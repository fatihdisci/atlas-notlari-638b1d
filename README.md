# Atlas Notları

Bu deponun web çıktısı kökteki `index.html` dosyasıdır. Dosya bir HTML kabuğu ve şifreli veri içerir. Kaynak belgeler, bir paket manifesti ve otomatik test takımı depoda yer almıyor.

## Bir ajanla çalışırken

Belge düzenlemesini README ile sınırlandır. Web çıktısının içeriğiyle ilgili bir görev için proje sahibinden düzenlenebilir kaynak ve beklenen çıktıyı al. Erişim bilgilerini örneklere veya commit'lere ekleme.

Belge güncellemesini `git diff --check` ile denetle. GitHub Pages ana daldan yayımlar. Dağıtım sonrasında Pages işinin sonucunu ve yayımlanan HTML'nin önceki sürümle aynı olduğunu kontrol edebilirsin.
